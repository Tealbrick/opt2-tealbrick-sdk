# @opt2-tealbrick/manifest

The one owner of opt2 contract primitives (SDK-API §2, CORE §3): manifest validator (schema + every MANIFEST cross-field rule), `validateInput`, `withStandardOps`, MCP tool names, `renderSkill`, RFC 8785 JCS + sha256 digests, Ed25519 keys and JWS (`signJws`, `signJwsWithSigner`, `verifyJws`), key sets and the announcement trust rule, assertions, AES-256-GCM sealing, opaque values, ULIDs, every token verifier and issuer-side signer (grant, call/hook/bridge-op proofs, tickets, config, slice, pairing code, agent session, release index), and the decision functions `gate()` (bridge) and `authorize()` (app).

Runtime deps: `@opt2-tealbrick/spec`, `ajv`. Node 24+. Copying any of these primitives elsewhere is a CI failure.

0.1.23 (spec 0.1.46, GRANT-PRD): the grant claim set accepts an optional `prd` (a product id, `^[a-z][a-z0-9-]{1,31}$`) for companion grants; `signGrant` and `verifyGrant` shape-check it. A verifier older than 0.1.23 refuses a grant that carries `prd` (closed claim set), so deploy readers before Core mints it.

0.1.24 (C238, C230, C232): `AGENT_DOCUMENT_RULES` is the rule list for agent-written HTML served as a `/_d/` document, as frozen data next to `VIEWER_HEADER_FLOOR` so that the SDK sanitiser, its tests and conformance read one list: the elements that are removed (`link` with every `rel`, `base`, `meta[http-equiv]`, `form`, frames, `object`/`embed`/`applet`/`portal`/`fencedframe`, `noscript`), the attributes that go (`ping`, `srcdoc`, `on*` unless the app opts into scripts), the URL attributes and the three allowed URL forms (a `#fragment`, a raster `data:image/...`, a path under the app's `assetPrefix`), the CSS image functions and at-rules (`url(`, `image(`, `image-set(`, `cross-fade(`, `element(`, `src(`, `@import`, with or without a vendor prefix), the SVG presentation attributes and SMIL attributes that get the same CSS check, and the limits (2 MiB input, tree depth, attributes per tag). With it `AGENT_DOCUMENT_MARKER` (`<!-- tb:sanitized v1 -->`), `AGENT_DOCUMENT_MAX_BYTES` and `AGENT_DOCUMENT_UNAVAILABLE_TEXT`. The manifest package holds no sanitiser and no HTML parser; `sanitizeAgentDocument()` is in `@opt2-tealbrick/miniapp-sdk` 0.1.29.
